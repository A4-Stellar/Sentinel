## Overview

The Sentinel GraphQL API is served at:

```
POST https://api.sentinel.a4stellar.com/graphql
```

It supports the same event query and subscription capabilities as the REST API, with the added flexibility of composable queries and field-level selection.

---

## Authentication

Pass your API key in the `X-API-Key` header (same as the REST API):

```bash
curl -X POST https://api.sentinel.a4stellar.com/graphql \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $SENTINEL_API_KEY" \
  -d '{ "query": "{ __typename }" }'
```
